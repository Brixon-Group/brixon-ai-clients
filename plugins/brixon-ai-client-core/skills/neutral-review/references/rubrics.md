# Review criteria by artifact type

Read only the section for the artifact under review.

## Copy

Judge the complete visible message in its intended language and audience context: is it clear
what is offered, for whom, and what the reader should do next? Preserve factual meaning, approved
terminology and valid brand constraints. Flag unsupported claims separately from clarity
problems. Do not apply a blanket ban on words; name the specific passage and why it fails.

## Rendered design

Judge the supplied viewport and image: hierarchy, legibility, alignment, contrast, interaction
cues and the relevant brand tokens (colors, fonts, spacing). Name what is visibly wrong and where.
An image alone does not prove responsive behavior, accessibility semantics or correct
implementation; ask for the relevant evidence when those are in scope.

## Documents

Judge structure, completeness against the brief, consistency of terms and numbers, and whether
every factual statement is supported by the supplied sources. Point to the exact page or section.

## Code

Use the supplied diff with enough surrounding code, interfaces and test results to check
correctness, security and compatibility. Prefer reproducible failures and specific unsupported
assumptions over style preferences. If essential context is missing, name the precise
uncertainty; do not invent unseen behavior. Report each issue with the triggering condition,
exact file and line, consequence and minimal fix.
